Files → detection → review → confirmation → CRM. Nothing is written to the CRM until you confirm it.

1. Import destination

Select where detected client and campaign data should be applied.

2. Add source material

Paste screenshots, drag files, upload spreadsheets/PDFs, or paste structured text.
Drop files, select multiple files, or paste screenshots with Ctrl+V / Cmd+V

Supported: XLSX, XLS, CSV, JSON, TXT, PDF, PNG, JPG and WEBP. For the smoothest one-file reservation import, use these headers exactly: Conf. Number, Room Type, Hotel, Check in, Check out, Member. “Días para check in” may stay in the file but is ignored and recalculated by the CRM. Missing owners in an XLS/XLSX/CSV are created as minimal client profiles automatically. Files containing reservations for multiple owners can be imported in one operation; each row is matched to an existing Client using the Member column. “Días para check in” is ignored as source data and recalculated by the CRM from the Check-in date. Spanish Excel dates such as “sábado, 19 de diciembre de 2026” are supported. You can also paste screenshots directly with Ctrl+V / Cmd+V.

Settings & System Health

Version Master 1.6 fixes CRM startup initialization and preserves all reservation import, room-capacity, points, campaign, report, backup and dashboard functions.

  • The CRM uses normalized IDs for clients, campaigns, KPI periods, reservations, documents and point rules.
  • Import Review Center requires confirmation before OCR/spreadsheet data is saved.
  • Reservation imports support XLS/XLSX/CSV and PNG/JPG/WEBP/PDF OCR with row-level validation.
  • Reports use fully-contained KPI periods for selected date ranges; partially overlapping aggregate periods are not silently prorated.
  • Full Backup includes both CRM data and locally stored document/Point Chart files.
  • OCR, XLSX parsing and dedicated PDF export use external libraries and therefore require internet access when those libraries are not already cached.
